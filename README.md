# PDF.js GitHub Pages viewer

This uses the original `Untitled-1.pdf` as the source and PDF.js to render it
inside the webpage. There is no browser PDF viewer toolbar, iframe, or PDF
viewer UI.

Files:
- `index.html`
- `Untitled-1.pdf`
- `assets\latest-banger.png`
- `assets\music.mp3`

replace 'music.mp3' to change music
replace 'latest-banger.png' to change textual image
replace 'Untitled-1.pdf' to change overall pdf content file

PDF.js is loaded from jsDelivr. PDF link annotations are recreated as clickable
HTML links.

GitHub Pages:
Settings → Pages → Deploy from branch → main → /(root)
by PARTIK
